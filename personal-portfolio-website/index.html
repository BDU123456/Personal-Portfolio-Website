Personal introduction

I'm Biruk Taye, a Full-Stack Developer who enjoys turning a problem into a working product. I started with structured programming and console applications, then moved into the web because I like seeing ideas become something a person can click, read, and trust.

My recent work includes building full-stack web applications using React, Node.js, and SQL databases, as well as this portfolio site built with semantic HTML, modern CSS, and vanilla JavaScript. I value clean structure, honest user feedback, and details that make a page feel considered.
